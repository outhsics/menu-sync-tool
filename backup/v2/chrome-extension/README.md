# 菜单同步工具 - Chrome 扩展版本

## 🎯 功能

一键将本地环境的菜单同步到生产环境，自动获取页面的登录凭证。

## 📦 安装方法

### 开发者模式安装（推荐）

1. 打开 Chrome 浏览器
2. 在地址栏输入：`chrome://extensions`
3. 打开右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择此文件夹：`/Users/terre/Documents/menu-sync-tool/chrome-extension`
6. 扩展安装完成！

## 🚀 使用方法

### 第一步：导出菜单（从本地环境）

1. 打开本地环境：http://localhost:8081
2. 登录系统
3. 点击 Chrome 工具栏的扩展图标
4. 在弹出的窗口中点击"📦 导出菜单数据"
5. 复制导出的数据

### 第二步：导入菜单（到生产环境）

1. 打开生产环境：https://dev-admin.bangyangjia.com
2. 登录系统
3. 点击 Chrome 工具栏的扩展图标
4. 粘贴刚才导出的数据到"导入"文本框
5. 点击"🚀 导入菜单数据"
6. 等待导入完成

### 第三步：刷新缓存

1. 进入【系统设置】→【菜单管理】
2. 点击【刷新菜单缓存】
3. 刷新页面（F5）
4. 检查菜单是否同步成功

## ✨ 优势

- ✅ 自动获取页面的登录凭证
- ✅ 不需要手动复制 token
- ✅ 操作简单，一键导出/导入
- ✅ 可以重复使用，不会重复添加

## 🔧 技术原理

扩展通过 Content Script 注入到页面中，可以访问：
- localStorage
- sessionStorage
- Cookie
- 页面的认证状态

这样就不需要用户手动复制 token 了！

## 📝 注意事项

1. 必须在已登录的页面使用
2. 只同步"一转工作台"、"二转工作台"、"三转工作台"的子菜单
3. 可以安全地重复运行，不会重复添加已存在的菜单

## 🐛 故障排除

### 扩展图标没反应
- 刷新当前页面后再试
- 检查是否已登录系统

### 导出/导入失败
- 打开开发者工具（F12）查看 Console 错误
- 确保已经登录系统
- 检查网络连接

## 📄 文件说明

- `manifest.json` - 扩展配置文件
- `popup.html` - 弹出窗口界面
- `popup.js` - 弹出窗口逻辑
- `content.js` - 注入页面的脚本（获取 token 和调用 API）
- `icon*.png` - 扩展图标
